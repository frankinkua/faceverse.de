# Faceverse (faceverse.de)

Category: metaverse-web3

## Concept
A showcase about digital avatars and faces in the metaverse: how avatars are made, privacy around facial data, and a fun in-browser generator that draws a unique geometric SVG avatar from any name typed in (deterministic hash, nothing uploaded, downloadable as SVG).

## Look
Vivid and futuristic: gradient iridescent violet-teal hero, glassmorphism cards, rounded modern sans.

Repo: https://github.com/frankinkua/faceverse.de
