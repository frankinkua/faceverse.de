# Faceverse (faceverse.de)

Category: metaverse-web3

## Concept
A showcase about digital avatars and faces in the metaverse: how avatars are made, privacy around facial data, and a fun in-browser generator that draws a unique geometric SVG avatar from any name typed in (deterministic hash, nothing uploaded, downloadable as SVG).

## Look
Vivid and futuristic: gradient iridescent violet-teal hero, glassmorphism cards, rounded modern sans.

## File Structure
- `index.html`: Main landing page with avatar generator and ~800 words of content.
- `styles.css`: CSS with CSS Variables, responsive grid, glassmorphism UI, and dark mode support.
- `main.js`: FNV-1a hashing and deterministic SVG generation logic running fully locally.
- `impressum.html` / `datenschutz.html`: Required legal pages.
- `404.html`: Custom error page.
- `favicon.svg`: Inline SVG favicon.
- `robots.txt` / `sitemap.xml`: Basic SEO setup.
